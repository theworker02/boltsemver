# boltsemver

Bolt URLs and semver query parts with stable normalization.

**Site:** https://theworker02.github.io/boltsemver/

## Install / run

```bash
git clone https://github.com/theworker02/boltsemver.git
cd boltsemver
node src/cli.js
node --test
```
